# 근거 매트릭스 (기분 x 분위기)

> 문헌 기반 규칙의 근거표. 근거 강도: A 무작위 실험 / B 메타분석·체계적 리뷰·대규모 관찰 / C 이론·간접 근거·추론.
> 아래 서지는 초록·요약 수준으로 확인했고, 인용 전에 원문을 확인해야 한다.

## 1. 분위기 x 기분

| 분위기 | 우울(반추) | 휴식 필요(주의 피로) | 기분 좋음 |
|---|---|---|---|
| 숲길 | + A (Bratman 2015) | + A (Berman 2008) | + B (Barton & Pretty 2010) |
| 큰 물가 | + B (물 가산) | + C | + B (물 가산) |
| 하천변 산책로 | + C | + C | + C |
| 숲속 계곡길 | + C (외진 느낌 주의) | + C | + C |
| 동네길 | 0 C | 0 또는 - C | 0 C |

## 2. 점수 규칙 (초안, 가설)

- 환경 기본 점수: 숲 + 물(큰 물은 가산)
- 우울: 자연 우대, 사람이 있는 물가·녹지 가산, 외진 숲길 감점
- 휴식 필요: 자연 우대, 도로변·동네길 감점, 난이도 낮게
- 기분 좋음: 물 가산, 활동 강도 높은 구간 허용
- 안전: 외진 정도는 가중치가 아니라 필터와 표시로 처리
- 근거 강도 가중 (임시): A=3, B=2, C=1

## 4. 한계

- 대부분 노출 후 변화를 본 연구라서 기분에 따른 환경 선택은 직접 근거가 없다.
- 해외 연구가 중심이라 서울 환경에 그대로 적용된다고 보장할 수 없다.
- 우리의 5개 분위기와 정확히 같은 환경을 다룬 연구는 찾지 못했다.
- 효과 크기는 연구마다 다르고 일부는 건강한 성인 대상이다.
