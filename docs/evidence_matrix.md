# 근거 매트릭스 (기분 x 분위기) v0.2

> 문헌 기반 규칙의 근거표. 근거 강도: A 무작위 실험 / B 메타분석·체계적 리뷰·대규모 관찰 / C 이론·간접 근거·추론.
> 아래 서지는 초록·요약 수준으로 확인했고, 인용 전에 원문을 확인해야 한다.

## 1. 분위기 x 기분

| 분위기 | 부정 기분(스트레스·반추) | 휴식 필요(주의 피로) | 기분 좋음 |
|---|---|---|---|
| 숲길 | + A (Bratman 2015, 스트레스 유발 실험들) | + A (Berman 2008) | + B (Barton & Pretty 2010) |
| 큰 물가 | + B (물 가산) | + C | + B (물 가산) |
| 하천변 산책로 | + C (서울 청계천 연구 있으나 결과 미확인) | + C | + C |
| 숲속 계곡길 | + C (외진 느낌 주의: Stragà 2023) | + C | + C |
| 동네길 | - A (자연보다 낮음, 번화가보단 나음) | 0 ~ - (리뷰 결과 엇갈림) | 0 C |

## 2. 점수 규칙 (초안, 가설)

- 환경 기본 점수: 숲 + 물(큰 물은 가산)
- 부정 기분: 자연 우대, 사람이 있는 물가·녹지 가산, 외진 숲길 감점
- 휴식 필요: 자연 우대, 도로변·번화가 감점, 난이도 낮게
- 기분 좋음: 근거가 약해 기분별 조정은 최소로 두고, 물 가산과 활동 허용 정도만 반영
- 동네길: 자연보다 낮게, 번화가보다는 높게
- 안전: 외진 정도는 가중치가 아니라 필터와 표시로 처리
- 근거 강도 가중 (임시): A=3, B=2, C=1

## 6. 한계

- 환경 효과 연구는 대부분 노출 후 변화를 본 것이고, 기분에 따른 환경 선택은 일부 실험(스트레스 유발 후 자연 선호)만 직접 근거가 있다.
- 그 실험들은 우울증이 아니라 영상으로 만든 일시적 스트레스를 다뤘다.
- 기분이 좋을 때의 환경 선호는 근거를 찾지 못했다.
- 해외 연구가 중심이라 서울 환경에 그대로 적용된다고 보장할 수 없다.
- 우리의 5개 분위기와 정확히 같은 환경을 다룬 연구는 찾지 못했다.
- 가상 산책이나 영상 실험은 실제 산책과 다를 수 있다.
