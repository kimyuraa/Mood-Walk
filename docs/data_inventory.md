## 5. 알려진 한계

- 서울둘레길 8코스는 외곽 산지 위주라서 **숲 분위기에 치우쳐 있음**. 물가·도심 코스는 다른 데이터로 보완해야 함.
- 서울둘레길 한 코스가 12~31km로 길어서 500m~1km 구간으로 쪼개서 써야 함.
- 지하철 좌표 오류는 서로 가까운 위치에 겹친 경우만 점검함. 서울 안의 다른 위치 오류는 못 잡았을 수 있음.
- OSM은 사용자가 입력한 데이터라서 누락이나 태그 불일치가 있을 수 있음.
- 공원 구분(`parkSe`) 분류가 이름과 맞지 않는 경우가 있어 숲 점수는 구분보다 면적과 이름을 함께 봄.
