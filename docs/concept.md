# Mood-Walk 컨셉 정의 (v0.2)

> v0.1은 가설에서 시작했고, v0.2는 서울둘레길 295구간을 군집화한 결과를 반영했다.
> 분위기 이름은 임시이며 지도 확인 후 확정한다.

## 1. 코스 단위

- 서울둘레길 8코스(약 147km)를 약 500m 구간 295개로 나눔 (구간 길이는 임시 기준)

## 2. 분위기 (데이터로 도출한 5개 군집, K=5)

| 분위기 (임시) | 구간 수 | 대표 특징 | 메모 |
|---|---|---|---|
| 숲길 | 133 | 코스 위 숲 비율 0.91, 오르내림 큼, 편의시설 많음 | 지하철·따릉이 접근성 낮음 |
| 큰 물가 | 44 | 큰 물 100m 이내 비율 0.88, 가장 평탄 | 44구간 중 28구간이 6코스 |
| 개울길 (숲 없음) | 30 | 개울 100m 이내 비율 0.88, 숲 거의 없음, 평탄 | 따릉이 평균 92m로 접근성 최고 |
| 숲속 계곡길 | 19 | 숲 0.83 + 개울 0.61 | 구간 수가 적음 |
| 특징 약한 길 | 69 | 숲·큰 물·개울 모두 약함 | 지도 확인 후 이름 확정 |

## 3. 도출 방법

| 항목 | 내용 |
|---|---|
| 군집화 변수 | 코스 위 숲 비율, 코스 300m 안 숲 비율, 큰 물 100m 이내 비율, 큰 물까지 거리(log), 개울 100m 이내 비율, 개울까지 거리(log) |
| 방법 | 표준화 후 KMeans (K=5) |
| 군집화에서 제외 | 난이도, 편의시설, 접근성 (필터와 설명용으로 사용) |
| 변수 근거 | PCA 앞 3개 성분이 분산의 약 93% 설명 → 숲, 큰 물, 개울의 3축 |
| 안정성 | 80% 부분표본 30회 ARI 평균 0.970 |
| 민감도 | K=4와 K=5의 ARI 0.956. 변수 세트를 바꾸면 ARI 0.5~0.8로 경계 구간 배정이 달라짐 |

## 4. 기분 → 분위기 (가설, 설문으로 검증 예정)

| 기분 | 어울릴 분위기 가설 |
|---|---|
| 우울 | 물가 계열 (큰 물가, 개울길) |
| 휴식 필요 | 숲 계열 (숲길, 숲속 계곡길) |
| 기분 좋음 | 미정 |

> 근거 없는 가설이다. 설문 결과로 기분별 선호를 추정해 바꾼다.

## 5. 필터 (분위기와 별개)

| 필터 | 기준 변수 |
|---|---|
| 난이도 | 평균 경사, 누적 오르내림 |
| 편의 | 쉼터·화장실·벤치·정자·음수대 개수 |
| 접근성 | 지하철역·따릉이 대여소까지 거리 |
| 이동 방식 | 걷기 / 자전거 (자전거는 따릉이 접근성을 임시 기준으로 사용) |

## 6. 보류와 한계

- **도심·조용함 보류**: 서울둘레길은 외곽 산지 위주라서 500m 안에 지하철역이 있는 구간이 드묾
- 큰 물가 구간이 6코스에 몰려 있어 물가 분위기의 코스 다양성이 낮음
- 숲길일수록 따릉이가 멀어서 자전거 모드는 별도 코스가 필요함
