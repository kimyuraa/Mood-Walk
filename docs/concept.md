# Mood-Walk 컨셉 정의

> 초안 (v0.1). 데이터 확인 후 수정 예정.

## 1. 분위기 정의

| 분위기 | 정의 | 측정 변수 | 필요 데이터 | 점수화 방식 | 한계 |
|---|---|---|---|---|---|
| 물가 | 코스 구간 중 수변에 가까운 비율이 높음 | 코스 좌표와 하천/강/호수 거리 (100m 이내 구간 비율) | 하천·호수 좌표, 코스 좌표 | 비율을 0~1로 정규화 | 하천 좌표 데이터 확보 여부 미확인 |
| 숲 | 녹지 비중이 높고 둘레길 성격 | 코스 주변 공원·녹지 면적, 둘레길 여부 | 공원 면적, 둘레길 노선 | 면적 분위수 점수 | 도시공원과 실제 숲의 차이 |
| 도심 | 상권이 가까워 활기 있음 | 코스 반경 내 상권/지하철역 개수 | 상권 정보, 지하철역 | 개수 분위수 점수 | 유동인구 데이터 없으면 대체 변수 사용 |
| 조용함 | 번잡하지 않음 | 도심 점수의 역수 (1 - 도심 점수) | 도심 점수 재활용 | 역수 | 도심 정의에 종속됨 |

## 2. 기분별 분위기 가설

| 기분 | 어울리는 분위기 (가설) | 가중치 (임시) |
|---|---|---|
| 우울 | 물가, 탁 트임 | 물가 0.5 / 숲 0.3 / 도심 0.1 / 조용함 0.1 |
| 휴식 필요 | 숲, 조용함 | 숲 0.4 / 조용함 0.4 / 물가 0.2 / 도심 0.0 |
| 기분 좋음 | 도심, 활기 | 도심 0.5 / 물가 0.3 / 숲 0.1 / 조용함 0.1 |

> 가중치는 임시값이고 근거 없는 가설이야. 3주차에 근거를 보강한다.

## 3. 설계 원칙

| 원칙 | 내용 |
|---|---|
| 상대 기준 | 절대값 대신 서울 코스 내 분위수로 점수화 |
| 다중 태그 | 한 코스에 여러 분위기 허용 (0~1 점수) |
| 데이터 우선 | 데이터 없는 기준은 대체 변수로 바꾸거나 제거 |

## 4. 열린 질문
